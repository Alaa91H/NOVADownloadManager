# YouTube Extension Handoff Review

**Date:** 2026-08-27
**Scope:** A bounded review of reliable browser-extension handoff for downloadable media, with YouTube as the primary reported failure surface after NOVA v2.4.36-alpha.

## NOVA baseline and observed issue

NOVA already contains a managed-media contract: `ADD_YTDLP_MEDIA` submits a stable page URL and a chosen format identifier to the local engine endpoint `/v1/media/add`. The in-page floating panel follows that contract and only reports success when the engine returns `accepted: true`.

The extension popup does not consistently follow the same boundary. Its generic candidate and quality flows send non-manifest selections through `DOWNLOAD_DIRECT`, including YouTube `googlevideo`/`videoplayback` candidates. Those URLs are ephemeral delivery URLs and can represent separate audio or video tracks; they bypass NOVA's managed yt-dlp resolve/merge route. The popup also has limited regression coverage for this path and may open as an empty compact surface when generic scanning does not yield a playable candidate.

The attached application log shows initial loopback request retries before the daemon connects, then repeated abort-originated retry warnings and one `saveConfigToDisk failed` warning. It contains no per-request media-engine failure details, so it cannot establish an engine extraction failure. It does establish that the extension and desktop readiness state must be presented clearly instead of treating transient startup state as a generic download failure.

## Bounded decision

The next implementation should align popup YouTube actions with the existing managed-media path. When the popup recognizes a YouTube page or candidate, it should probe the stable page URL through the desktop engine, require a selectable `formatId`, submit `ADD_YTDLP_MEDIA`, and only show success after explicit daemon acceptance. It should not forward transient CDN URLs as direct downloads, manufacture browser cookies, bypass access controls, or expose authentication information.

A complementary UX improvement should give the popup an explicit media-ready state on YouTube pages and distinguish desktop-not-ready, probe-in-progress, no-format, accepted, and rejected states. Any new user-visible copy must be completely localized across the maintained catalog; otherwise the improvement must reuse existing translations or defer the new copy.
